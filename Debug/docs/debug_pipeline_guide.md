# YOLO-only セグメンテーション デバッグツール ガイド

YOLO モデル単体で動画のセグメンテーション推論を実行し、
結果をオーバーレイした動画を出力するデバッグ用スクリプトです。

---

## 概要

`mosaic_yolov26_yoloonly_debug.py` は以下を行います：

1. 入力動画を1フレームずつ読み込み
2. 各フレームに対して YOLO セグメンテーション推論を実行
3. 検出マスクを緑色でオーバーレイ
4. デバッグ情報（フレーム番号、検出数など）をフレームに描画
5. オーバーレイ済みフレームを動画としてエンコード・出力

```
入力MP4 → [YOLO推論] → [マスクオーバーレイ] → [デバッグ情報描画] → 出力MP4
```

---

## 使い方

### 前提条件

- Python 3.8+
- CUDA 対応 GPU（必須）
- YOLOモデルファイル（`.pt`）をスクリプトと同じフォルダに配置

### 必要なパッケージ

```bash
pip install ultralytics torch opencv-python av rich psutil
```

### 実行

```bash
python mosaic_yolov26_yoloonly_debug.py
```

1. ダイアログで **入力フォルダー** を選択（MP4ファイルが入っているフォルダー）
2. ダイアログで **出力フォルダー** を選択
3. フォルダー内の全MP4が順番に処理される

### 出力ファイル

```
出力フォルダー/
└── {元ファイル名}_yoloonly.mp4    ← マスクオーバーレイ済み動画
```

## 設定パラメータ

スクリプト冒頭で調整可能な値：

| パラメータ | デフォルト | 説明 |
|-----------|-----------|------|
| `CONF_THRESHOLD` | 0.15 | マスク表示の最終信頼度閾値。これ未満の検出は除外 |
| `MASK_ALPHA` | 0.45 | マスクオーバーレイの透明度（0=透明、1=不透明） |
| `MASK_THRESH` | 0.5 | マスクの二値化閾値。ピクセルごとにマスク判定 |
| `YOLO_CONF` | 0.1 | YOLO推論時の信頼度閾値。低いほど多く検出 |
| `MAX_ANCHOR_OBJECTS` | 5 | 1フレームあたりの最大オーバーレイ数 |

### パラメータ調整の指針

- **偽陽性が多い場合** → `CONF_THRESHOLD` を 0.25〜0.3 に上げる
- **検出漏れが多い場合** → `YOLO_CONF` を 0.05 に下げる
- **マスクが見づらい場合** → `MASK_ALPHA` を 0.6〜0.7 に上げる
- **密集シーンでマスクが足りない場合** → `MAX_ANCHOR_OBJECTS` を 10 に上げる

## 処理パイプラインの詳細

### 1. YOLOモデルの自動検出

スクリプトと同じディレクトリから `.pt` ファイルを自動検索します。
複数ある場合は最初に見つかったものを使用します。

### 2. エンコーダー選択

GPU エンコード（`h264_nvenc`）を優先的に試行し、
利用できない場合は CPU エンコード（`libx264`）にフォールバックします。

### 3. フレーム処理フロー

```
フレーム取得 (PyAV)
    ↓
YOLO推論 (GPU, torch.no_grad)
    ↓
マスク抽出 → bilinear補間でフレームサイズにリサイズ
    ↓
マスク合成 (GPU上でbool OR演算)
    ↓
緑色オーバーレイ (GPU上でアルファブレンド)
    ↓
マスク領域に "YOLO" テキスト描画
    ↓
デバッグオーバーレイ (フレーム番号、検出数)
    ↓
エンコード・出力
```

### 4. メモリ管理

- 推定メモリ使用量: ~4GB（YOLOモデル + 1フレーム分）
- 500フレームごとにRAM/VRAMの使用状況をログ出力
- フレームは逐次処理のためメモリ蓄積なし

## データセット分析との関連

このデバッグツールの出力結果と、`Analyze/` フォルダの分析レポートを
組み合わせて評価することで、モデル改善の方向性を判断できます。

| 分析レポートの指摘 | デバッグ動画で確認すべきこと |
|-------------------|---------------------------|
| tiny objects = 18.7% | 小物体が検出できているか |
| spatial_cv = 1.24（偏りあり） | 画像端のオブジェクトが検出できているか |
| edge_touch = 48.4%（cls 1_1） | 画面端で切れた対象の検出精度 |
| overlap IoU >= 0.1 = 23.1% | 重なり合う対象が正しく分離されているか |
| mean_vertices = 123 | マスク境界が対象の輪郭に沿っているか |

## トラブルシューティング

| 症状 | 原因 | 対処 |
|------|------|------|
| 「CUDAが使えません」 | GPU未検出 | CUDA対応GPUとドライバを確認 |
| 「YOLOモデルが見つかりません」 | `.pt` ファイルがない | スクリプトと同じフォルダに配置 |
| 出力動画が真っ黒 | エンコーダーの問題 | `pick_encoder()` のログを確認 |
| VRAM不足エラー | モデル+フレームがVRAMに収まらない | 入力解像度を下げるか、小さいモデルを使用 |
| 処理が遅い（<10fps） | CPU エンコーダーが選択されている | NVENC対応GPUを使用 |
